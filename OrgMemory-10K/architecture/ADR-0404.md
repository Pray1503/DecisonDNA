# ADR-0404: Migrate visionai-inference frontend architecture to React / Next.js

* **Status:** Accepted
* **Date:** 2025-02-23
* **Related Project:** PRJ-014
* **Owner:** EMP-031
* **Complexity:** High
* **Priority:** Medium
* **Tags:** frontend, framework, performance

## Context
The legacy user interface of visionai-inference is written in a monolithic, unmaintained framework. It leads to slow page loads, poor SEO, and difficulty in writing modern components.

## Problem
Bundle size is too large (5MB+), page interactive time (TTI) is over 6 seconds, and developers find it slow to build features.

## Alternatives Considered
1. Refactor the existing legacy code and optimize bundle sizes.
2. Migrate to Vanilla JS and web components.
3. Rebuild the frontend using React / Next.js.

## Decision
Rebuild and migrate the UI for visionai-inference to React / Next.js.

## Rationale
React / Next.js offers Server-Side Rendering (SSR) / Static Site Generation (SSG), excellent component ecosystem, and faster developer onboarding.

## Consequences
Full frontend rewrite is needed. Existing component libraries must be recreated or migrated.

## Expected Benefits
First Contentful Paint (FCP) improved from 4s to 1.2s; developer velocity increased.

## Potential Risks
Delays in feature parity during migration, state management refactoring challenges, and framework updates overhead.
