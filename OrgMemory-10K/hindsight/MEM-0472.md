# Decision Memory Object: MEM-0472 (Migrate fusionerp-frontend frontend architecture to React / Next.js)

* **Original ADR:** [ADR-0472](../architecture/ADR-0472.md)
* **Status:** Proposed
* **Memory Version:** v1.0.0
* **Operational Confidence Score:** 1.00 (Scale: 0.0 - 1.0)

## 1. Context and Problem
The legacy user interface of fusionerp-frontend is written in a monolithic, unmaintained framework. It leads to slow page loads, poor SEO, and difficulty in writing modern components.

* **Problem Statement:** Bundle size is too large (5MB+), page interactive time (TTI) is over 6 seconds, and developers find it slow to build features.

## 2. Alternatives Considered
1. Refactor the existing legacy code and optimize bundle sizes.
2. Migrate to Vanilla JS and web components.
3. Rebuild the frontend using React / Next.js.

## 3. Decision & Technical Direction
Rebuild and migrate the UI for fusionerp-frontend to React / Next.js.
