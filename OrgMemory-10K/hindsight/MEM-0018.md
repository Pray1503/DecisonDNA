# Decision Memory Object: MEM-0018 (Migrate visionai-pipeline frontend architecture to Angular)

* **Original ADR:** [ADR-0018](../architecture/ADR-0018.md)
* **Status:** Accepted
* **Memory Version:** v1.0.0
* **Operational Confidence Score:** 0.40 (Scale: 0.0 - 1.0)

## 1. Context and Problem
The legacy user interface of visionai-pipeline is written in a monolithic, unmaintained framework. It leads to slow page loads, poor SEO, and difficulty in writing modern components.

* **Problem Statement:** Bundle size is too large (5MB+), page interactive time (TTI) is over 6 seconds, and developers find it slow to build features.

## 2. Alternatives Considered
1. Refactor the existing legacy code and optimize bundle sizes.
2. Migrate to Vanilla JS and web components.
3. Rebuild the frontend using Angular.

## 3. Decision & Technical Direction
Rebuild and migrate the UI for visionai-pipeline to Angular.

## 7. Lessons Learned & Retrospective
Full frontend rewrite is needed. Existing component libraries must be recreated or migrated.
