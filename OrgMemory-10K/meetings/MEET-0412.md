## Agenda
Design Review: Migrate visionai-inference frontend architecture to React / Next.js

## Discussion
The team discussed the problem: 'Bundle size is too large (5MB+), page interactive time (TTI) is over 6 seconds, and developers find it slow to build features.'. Author EMP-031 presented the proposal to: 'Rebuild and migrate the UI for visionai-inference to React / Next.js.'. We reviewed alternatives: 1. Refactor the existing legacy code and optimize bundle sizes.
2. Migrate to Vanilla JS and web components.
3. Rebuild the frontend using React / Next.js.. Feedback was mostly positive regarding the expected benefits: 'First Contentful Paint (FCP) improved from 4s to 1.2s; developer velocity increased.'. SRE raised concerns on potential risks: 'Delays in feature parity during migration, state management refactoring challenges, and framework updates overhead.', which we decided to mitigate by scaling up monitoring.

## Decisions Made
Approved implementation of decision. EMP-031 to publish official ADR and create Jira implementation tasks.
