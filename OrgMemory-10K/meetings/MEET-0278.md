## Discussion
Reviewing outage incident INC-0006 on cloudsync-desktop. Root Cause: A memory leak in the Go/Python worker loop processing batch uploads. The worker accumulated pointers in a global slice and did not trigger garbage collection timely. Pod reached K8s limit (2Gi) and got OOMKilled.. Lessons learned: Profile heap usage during batch tasks, reuse object buffers, and add strict memory limits to K8s configs with warnings at 80% usage.

## Decisions Made
Resolve post-mortem tasks. Approved mitigation and preventative actions: Profile heap usage during batch tasks, reuse object buffers, and add strict memory limits to K8s configs with warnings at 80% usage.
