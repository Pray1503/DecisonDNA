## Agenda
Design Review: Use Nomad to deploy platform-monitoring to AWS

## Discussion
The team discussed the problem: 'Deployment takes over 40 minutes, and we lack auto-scaling. Small configuration drift on VMs makes debugging environments difficult.'. Author EMP-150 presented the proposal to: 'Standardize all microservice deployments, starting with platform-monitoring, on Nomad hosted on AWS.'. We reviewed alternatives: 1. Script VM creation using custom Ansible and AMI images.
2. Deploy directly to AWS ECS.
3. Implement a complete Nomad container orchestration architecture.. Feedback was mostly positive regarding the expected benefits: 'Deployment time down from 40m to under 5m; auto-scaling responds to traffic load in under 2m.'. SRE raised concerns on potential risks: 'Steep learning curve for the team, complex networking policies, and increased infrastructure cost for the control plane.', which we decided to mitigate by scaling up monitoring.

## Decisions Made
Approved implementation of decision. EMP-150 to publish official ADR and create Jira implementation tasks.
