## Discussion
Reviewing outage incident INC-0004 on atlaspay-ledger. Root Cause: An eviction of high-frequency metadata cache keys in Redis occurred concurrently with a traffic spike. Thousands of pods hit the underlying database at once to re-fetch the metadata, locking tables.. Lessons learned: Implement cache key locking/mutexes (single-flight pattern) so only one request updates the cache while others wait. Add jitter to cache TTLs.

## Decisions Made
Resolve post-mortem tasks. Approved mitigation and preventative actions: Implement cache key locking/mutexes (single-flight pattern) so only one request updates the cache while others wait. Add jitter to cache TTLs.
