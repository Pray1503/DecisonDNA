Post-Mortem: Outage INC-0010 - Database connection pool exhaustion on security-scanner

## Discussion
Reviewing outage incident INC-0010 on security-scanner. Root Cause: The service connection pool size was set to 20, but under heavy concurrent traffic, queries blocked on database, causing requests to queue up and exhaust all worker threads. The health check endpoint also blocked, leading Kubernetes to restart pods in a loop.. Lessons learned: We must decoupled health check endpoints from primary database checks (make them shallow), increase connection pool limits, and implement rate limiting on expensive endpoints.

## Decisions Made
Resolve post-mortem tasks. Approved mitigation and preventative actions: We must decoupled health check endpoints from primary database checks (make them shallow), increase connection pool limits, and implement rate limiting on expensive endpoints.
