# Incident Report: INC-0046 - Routing loop in Istio service mesh for visionai-inference

* **Severity:** P0
* **Linked Deployment:** DEP-0098
* **Linked PR:** PR-0029
* **Linked ADR:** ADR-0007

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-03-06 02:47:00**: System Alert - Anomalous Metrics Detected
- **2021-03-06 03:01:00**: On-call Engineer Acknowledged Alert
- **2021-03-06 03:38:00**: Mitigation Applied - Flushed cache
- **2021-03-06 05:49:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 03:38:00 by rolling back production deployment DEP-0098 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
