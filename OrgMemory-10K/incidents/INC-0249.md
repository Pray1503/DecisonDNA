# Incident Report: INC-0249 - Message lag spike on Kafka partition for cloudsync-daemon

* **Severity:** P1
* **Linked Deployment:** DEP-0517
* **Linked PR:** PR-0257
* **Linked ADR:** ADR-0064

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-10-20 21:17:00**: System Alert - Anomalous Metrics Detected
- **2021-10-20 21:19:00**: On-call Engineer Acknowledged Alert
- **2021-10-20 21:46:00**: Mitigation Applied - Rolled back deployment
- **2021-10-20 23:12:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 21:46:00 by rolling back production deployment DEP-0517 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
