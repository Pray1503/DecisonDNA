# Incident Report: INC-0344 - Unoptimized query on novacommerce-checkout database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0714
* **Linked PR:** PR-0359
* **Linked ADR:** ADR-0086

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2022-01-15 10:06:00**: System Alert - Anomalous Metrics Detected
- **2022-01-15 10:17:00**: On-call Engineer Acknowledged Alert
- **2022-01-15 10:58:00**: Mitigation Applied - Rolled back deployment
- **2022-01-15 13:42:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 10:58:00 by rolling back production deployment DEP-0714 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
