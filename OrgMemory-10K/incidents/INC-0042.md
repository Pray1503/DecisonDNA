# Incident Report: INC-0042 - Routing loop in Istio service mesh for novacommerce-cart

* **Severity:** P0
* **Linked Deployment:** DEP-0092
* **Linked PR:** PR-0048
* **Linked ADR:** ADR-0014

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-03-01 11:44:00**: System Alert - Anomalous Metrics Detected
- **2021-03-01 11:51:00**: On-call Engineer Acknowledged Alert
- **2021-03-01 13:01:00**: Mitigation Applied - Increased pod count
- **2021-03-01 15:26:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 13:01:00 by rolling back production deployment DEP-0092 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
