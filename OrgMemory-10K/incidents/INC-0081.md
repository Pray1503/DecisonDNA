# Incident Report: INC-0081 - Cache stampede in atlaspay-ledger for metadata queries

* **Severity:** P1
* **Linked Deployment:** DEP-0171
* **Linked PR:** PR-0087
* **Linked ADR:** None

## Root Cause Summary
An eviction of high-frequency metadata cache keys in Redis occurred concurrently with a traffic spike. Thousands of pods hit the underlying database at once to re-fetch the metadata, locking tables.

## Incident Timeline
- **2021-04-06 08:34:00**: System Alert - Anomalous Metrics Detected
- **2021-04-06 08:42:00**: On-call Engineer Acknowledged Alert
- **2021-04-06 09:46:00**: Mitigation Applied - Rolled back deployment
- **2021-04-06 12:46:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 09:46:00 by rolling back production deployment DEP-0171 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement cache key locking/mutexes (single-flight pattern) so only one request updates the cache while others wait. Add jitter to cache TTLs.
