# Incident Report: INC-0341 - Routing loop in Istio service mesh for visionai-inference

* **Severity:** P0
* **Linked Deployment:** DEP-0706
* **Linked PR:** PR-0357
* **Linked ADR:** ADR-0087

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2022-01-14 14:33:00**: System Alert - Anomalous Metrics Detected
- **2022-01-14 14:46:00**: On-call Engineer Acknowledged Alert
- **2022-01-14 16:06:00**: Mitigation Applied - Increased pod count
- **2022-01-14 18:31:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 16:06:00 by rolling back production deployment DEP-0706 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
