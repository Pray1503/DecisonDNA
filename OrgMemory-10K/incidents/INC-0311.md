# Incident Report: INC-0311 - Message lag spike on Kafka partition for novacommerce-cart

* **Severity:** P1
* **Linked Deployment:** DEP-0646
* **Linked PR:** PR-0319
* **Linked ADR:** ADR-0076

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-12-19 07:20:00**: System Alert - Anomalous Metrics Detected
- **2021-12-19 07:25:00**: On-call Engineer Acknowledged Alert
- **2021-12-19 08:19:00**: Mitigation Applied - Increased pod count
- **2021-12-19 11:43:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 08:19:00 by rolling back production deployment DEP-0646 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
