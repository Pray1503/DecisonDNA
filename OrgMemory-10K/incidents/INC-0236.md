# Incident Report: INC-0236 - Routing loop in Istio service mesh for platform-logging

* **Severity:** P0
* **Linked Deployment:** DEP-0491
* **Linked PR:** PR-0231
* **Linked ADR:** ADR-0060

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-10-07 07:41:00**: System Alert - Anomalous Metrics Detected
- **2021-10-07 07:56:00**: On-call Engineer Acknowledged Alert
- **2021-10-07 09:04:00**: Mitigation Applied - Rolled back deployment
- **2021-10-07 10:42:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 09:04:00 by rolling back production deployment DEP-0491 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
