# Incident Report: INC-0354 - Unoptimized query on cloudsync-desktop database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0742
* **Linked PR:** PR-0378
* **Linked ADR:** ADR-0092

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2022-01-25 02:05:00**: System Alert - Anomalous Metrics Detected
- **2022-01-25 02:16:00**: On-call Engineer Acknowledged Alert
- **2022-01-25 02:33:00**: Mitigation Applied - Flushed cache
- **2022-01-25 03:16:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 02:33:00 by rolling back production deployment DEP-0742 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
