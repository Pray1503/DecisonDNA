# Incident Report: INC-0342 - Routing loop in Istio service mesh for insightcrm-analytics

* **Severity:** P0
* **Linked Deployment:** DEP-0712
* **Linked PR:** PR-0367
* **Linked ADR:** ADR-0088

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2022-01-14 16:34:00**: System Alert - Anomalous Metrics Detected
- **2022-01-14 16:45:00**: On-call Engineer Acknowledged Alert
- **2022-01-14 17:21:00**: Mitigation Applied - Flushed cache
- **2022-01-14 20:30:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 17:21:00 by rolling back production deployment DEP-0712 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
