# Incident Report: INC-0008 - Routing loop in Istio service mesh for security-scanner

* **Severity:** P0
* **Linked Deployment:** DEP-0017
* **Linked PR:** PR-0011
* **Linked ADR:** ADR-0002

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-01-27 18:52:00**: System Alert - Anomalous Metrics Detected
- **2021-01-27 19:02:00**: On-call Engineer Acknowledged Alert
- **2021-01-27 20:08:00**: Mitigation Applied - Flushed cache
- **2021-01-28 00:04:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 20:08:00 by rolling back production deployment DEP-0017 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
