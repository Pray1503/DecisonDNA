# Incident Report: INC-0226 - Message lag spike on Kafka partition for security-auth-proxy

* **Severity:** P1
* **Linked Deployment:** DEP-0470
* **Linked PR:** PR-0218
* **Linked ADR:** ADR-0056

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-09-24 16:33:00**: System Alert - Anomalous Metrics Detected
- **2021-09-24 16:39:00**: On-call Engineer Acknowledged Alert
- **2021-09-24 18:09:00**: Mitigation Applied - Rolled back deployment
- **2021-09-24 21:37:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 18:09:00 by rolling back production deployment DEP-0470 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
