# Incident Report: INC-0352 - Message lag spike on Kafka partition for insightcrm-analytics

* **Severity:** P1
* **Linked Deployment:** DEP-0733
* **Linked PR:** PR-0368
* **Linked ADR:** ADR-0088

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2022-01-22 01:22:00**: System Alert - Anomalous Metrics Detected
- **2022-01-22 01:36:00**: On-call Engineer Acknowledged Alert
- **2022-01-22 02:33:00**: Mitigation Applied - Rolled back deployment
- **2022-01-22 05:37:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 02:33:00 by rolling back production deployment DEP-0733 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
