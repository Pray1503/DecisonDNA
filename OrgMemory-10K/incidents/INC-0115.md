# Incident Report: INC-0115 - Routing loop in Istio service mesh for cloudsync-daemon

* **Severity:** P0
* **Linked Deployment:** DEP-0241
* **Linked PR:** PR-0122
* **Linked ADR:** ADR-0032

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-05-10 09:09:00**: System Alert - Anomalous Metrics Detected
- **2021-05-10 09:18:00**: On-call Engineer Acknowledged Alert
- **2021-05-10 10:21:00**: Mitigation Applied - Rolled back deployment
- **2021-05-10 13:26:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 10:21:00 by rolling back production deployment DEP-0241 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
