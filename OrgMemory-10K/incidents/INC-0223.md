# Incident Report: INC-0223 - Routing loop in Istio service mesh for atlaspay-gateway

* **Severity:** P0
* **Linked Deployment:** DEP-0466
* **Linked PR:** PR-0233
* **Linked ADR:** ADR-0061

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-09-22 13:52:00**: System Alert - Anomalous Metrics Detected
- **2021-09-22 14:06:00**: On-call Engineer Acknowledged Alert
- **2021-09-22 15:25:00**: Mitigation Applied - Flushed cache
- **2021-09-22 17:45:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 15:25:00 by rolling back production deployment DEP-0466 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
