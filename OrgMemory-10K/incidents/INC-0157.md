# Incident Report: INC-0157 - Message lag spike on Kafka partition for cloudsync-desktop

* **Severity:** P1
* **Linked Deployment:** DEP-0332
* **Linked PR:** PR-0171
* **Linked ADR:** ADR-0043

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-07-08 17:16:00**: System Alert - Anomalous Metrics Detected
- **2021-07-08 17:27:00**: On-call Engineer Acknowledged Alert
- **2021-07-08 18:55:00**: Mitigation Applied - Rolled back deployment
- **2021-07-08 19:45:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 18:55:00 by rolling back production deployment DEP-0332 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
