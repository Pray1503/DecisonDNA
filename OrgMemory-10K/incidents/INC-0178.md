# Incident Report: INC-0178 - Routing loop in Istio service mesh for atlaspay-portal

* **Severity:** P0
* **Linked Deployment:** DEP-0373
* **Linked PR:** PR-0184
* **Linked ADR:** ADR-0045

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-07-31 05:32:00**: System Alert - Anomalous Metrics Detected
- **2021-07-31 05:34:00**: On-call Engineer Acknowledged Alert
- **2021-07-31 06:45:00**: Mitigation Applied - Increased pod count
- **2021-07-31 09:10:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 06:45:00 by rolling back production deployment DEP-0373 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
