# Incident Report: INC-0286 - Message lag spike on Kafka partition for visionai-training

* **Severity:** P1
* **Linked Deployment:** DEP-0592
* **Linked PR:** PR-0298
* **Linked ADR:** ADR-0072

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-11-25 08:41:00**: System Alert - Anomalous Metrics Detected
- **2021-11-25 08:56:00**: On-call Engineer Acknowledged Alert
- **2021-11-25 10:18:00**: Mitigation Applied - Rolled back deployment
- **2021-11-25 13:01:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 10:18:00 by rolling back production deployment DEP-0592 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
