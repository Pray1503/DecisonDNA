# Incident Report: INC-0308 - Message lag spike on Kafka partition for novacommerce-cart

* **Severity:** P1
* **Linked Deployment:** DEP-0641
* **Linked PR:** PR-0329
* **Linked ADR:** ADR-0078

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-12-18 14:53:00**: System Alert - Anomalous Metrics Detected
- **2021-12-18 14:59:00**: On-call Engineer Acknowledged Alert
- **2021-12-18 15:44:00**: Mitigation Applied - Flushed cache
- **2021-12-18 16:54:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 15:44:00 by rolling back production deployment DEP-0641 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
