# Incident Report: INC-0258 - Routing loop in Istio service mesh for insightcrm-api

* **Severity:** P0
* **Linked Deployment:** DEP-0538
* **Linked PR:** PR-0248
* **Linked ADR:** ADR-0062

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-10-28 15:22:00**: System Alert - Anomalous Metrics Detected
- **2021-10-28 15:26:00**: On-call Engineer Acknowledged Alert
- **2021-10-28 15:51:00**: Mitigation Applied - Rolled back deployment
- **2021-10-28 19:20:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 15:51:00 by rolling back production deployment DEP-0538 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
