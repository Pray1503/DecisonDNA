# Incident Report: INC-0271 - Routing loop in Istio service mesh for security-auth-proxy

* **Severity:** P0
* **Linked Deployment:** DEP-0562
* **Linked PR:** PR-0292
* **Linked ADR:** ADR-0069

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-11-08 20:48:00**: System Alert - Anomalous Metrics Detected
- **2021-11-08 20:57:00**: On-call Engineer Acknowledged Alert
- **2021-11-08 21:32:00**: Mitigation Applied - Flushed cache
- **2021-11-08 23:58:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 21:32:00 by rolling back production deployment DEP-0562 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
