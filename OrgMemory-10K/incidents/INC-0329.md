# Incident Report: INC-0329 - Routing loop in Istio service mesh for novacommerce-cart

* **Severity:** P0
* **Linked Deployment:** DEP-0680
* **Linked PR:** PR-0315
* **Linked ADR:** ADR-0076

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2022-01-03 21:09:00**: System Alert - Anomalous Metrics Detected
- **2022-01-03 21:18:00**: On-call Engineer Acknowledged Alert
- **2022-01-03 21:46:00**: Mitigation Applied - Increased pod count
- **2022-01-04 01:46:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 21:46:00 by rolling back production deployment DEP-0680 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
