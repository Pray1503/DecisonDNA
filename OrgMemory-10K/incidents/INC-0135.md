# Incident Report: INC-0135 - Message lag spike on Kafka partition for atlaspay-ledger

* **Severity:** P1
* **Linked Deployment:** DEP-0284
* **Linked PR:** PR-0148
* **Linked ADR:** ADR-0036

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-05-29 22:44:00**: System Alert - Anomalous Metrics Detected
- **2021-05-29 22:46:00**: On-call Engineer Acknowledged Alert
- **2021-05-29 23:57:00**: Mitigation Applied - Flushed cache
- **2021-05-30 01:54:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 23:57:00 by rolling back production deployment DEP-0284 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
