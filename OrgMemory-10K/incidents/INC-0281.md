# Incident Report: INC-0281 - Routing loop in Istio service mesh for fusionerp-frontend

* **Severity:** P0
* **Linked Deployment:** DEP-0582
* **Linked PR:** PR-0300
* **Linked ADR:** None

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-11-18 16:27:00**: System Alert - Anomalous Metrics Detected
- **2021-11-18 16:34:00**: On-call Engineer Acknowledged Alert
- **2021-11-18 17:14:00**: Mitigation Applied - Flushed cache
- **2021-11-18 18:16:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 17:14:00 by rolling back production deployment DEP-0582 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
