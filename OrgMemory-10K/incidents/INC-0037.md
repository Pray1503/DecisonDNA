# Incident Report: INC-0037 - Message lag spike on Kafka partition for atlaspay-ledger

* **Severity:** P1
* **Linked Deployment:** DEP-0079
* **Linked PR:** PR-0045
* **Linked ADR:** None

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-02-20 22:46:00**: System Alert - Anomalous Metrics Detected
- **2021-02-20 22:56:00**: On-call Engineer Acknowledged Alert
- **2021-02-20 23:39:00**: Mitigation Applied - Flushed cache
- **2021-02-21 01:34:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 23:39:00 by rolling back production deployment DEP-0079 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
