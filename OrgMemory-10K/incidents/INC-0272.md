# Incident Report: INC-0272 - Routing loop in Istio service mesh for platform-k8s-mesh

* **Severity:** P0
* **Linked Deployment:** DEP-0564
* **Linked PR:** PR-0289
* **Linked ADR:** ADR-0068

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-11-09 07:57:00**: System Alert - Anomalous Metrics Detected
- **2021-11-09 08:00:00**: On-call Engineer Acknowledged Alert
- **2021-11-09 08:37:00**: Mitigation Applied - Rolled back deployment
- **2021-11-09 11:26:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 08:37:00 by rolling back production deployment DEP-0564 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
