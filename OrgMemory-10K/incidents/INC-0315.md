# Incident Report: INC-0315 - Message lag spike on Kafka partition for atlaspay-portal

* **Severity:** P1
* **Linked Deployment:** DEP-0654
* **Linked PR:** PR-0305
* **Linked ADR:** ADR-0073

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-12-22 09:00:00**: System Alert - Anomalous Metrics Detected
- **2021-12-22 09:03:00**: On-call Engineer Acknowledged Alert
- **2021-12-22 09:39:00**: Mitigation Applied - Increased pod count
- **2021-12-22 12:42:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 09:39:00 by rolling back production deployment DEP-0654 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
