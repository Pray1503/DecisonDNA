# Incident Report: INC-0317 - Cache stampede in atlaspay-ledger for metadata queries

* **Severity:** P1
* **Linked Deployment:** DEP-0658
* **Linked PR:** PR-0309
* **Linked ADR:** ADR-0074

## Root Cause Summary
An eviction of high-frequency metadata cache keys in Redis occurred concurrently with a traffic spike. Thousands of pods hit the underlying database at once to re-fetch the metadata, locking tables.

## Incident Timeline
- **2021-12-25 23:39:00**: System Alert - Anomalous Metrics Detected
- **2021-12-25 23:49:00**: On-call Engineer Acknowledged Alert
- **2021-12-26 00:33:00**: Mitigation Applied - Rolled back deployment
- **2021-12-26 01:41:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 00:33:00 by rolling back production deployment DEP-0658 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement cache key locking/mutexes (single-flight pattern) so only one request updates the cache while others wait. Add jitter to cache TTLs.
