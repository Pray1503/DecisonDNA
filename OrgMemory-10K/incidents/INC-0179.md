# Incident Report: INC-0179 - Routing loop in Istio service mesh for novacommerce-ui

* **Severity:** P0
* **Linked Deployment:** DEP-0375
* **Linked PR:** PR-0187
* **Linked ADR:** ADR-0050

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-07-31 08:07:00**: System Alert - Anomalous Metrics Detected
- **2021-07-31 08:15:00**: On-call Engineer Acknowledged Alert
- **2021-07-31 08:46:00**: Mitigation Applied - Rolled back deployment
- **2021-07-31 11:14:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 08:46:00 by rolling back production deployment DEP-0375 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
