# Incident Report: INC-0194 - Routing loop in Istio service mesh for novacommerce-ui

* **Severity:** P0
* **Linked Deployment:** DEP-0407
* **Linked PR:** PR-0209
* **Linked ADR:** ADR-0052

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-08-25 15:23:00**: System Alert - Anomalous Metrics Detected
- **2021-08-25 15:26:00**: On-call Engineer Acknowledged Alert
- **2021-08-25 16:05:00**: Mitigation Applied - Flushed cache
- **2021-08-25 18:09:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 16:05:00 by rolling back production deployment DEP-0407 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
