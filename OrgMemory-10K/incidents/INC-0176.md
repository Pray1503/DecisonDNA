# Incident Report: INC-0176 - Message lag spike on Kafka partition for cloudsync-desktop

* **Severity:** P1
* **Linked Deployment:** DEP-0365
* **Linked PR:** PR-0167
* **Linked ADR:** ADR-0043

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-07-30 22:42:00**: System Alert - Anomalous Metrics Detected
- **2021-07-30 22:49:00**: On-call Engineer Acknowledged Alert
- **2021-07-31 00:11:00**: Mitigation Applied - Flushed cache
- **2021-07-31 02:05:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 00:11:00 by rolling back production deployment DEP-0365 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
