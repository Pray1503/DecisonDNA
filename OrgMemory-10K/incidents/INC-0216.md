# Incident Report: INC-0216 - Routing loop in Istio service mesh for novacommerce-ui

* **Severity:** P0
* **Linked Deployment:** DEP-0448
* **Linked PR:** PR-0204
* **Linked ADR:** ADR-0052

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-09-13 22:34:00**: System Alert - Anomalous Metrics Detected
- **2021-09-13 22:39:00**: On-call Engineer Acknowledged Alert
- **2021-09-13 23:54:00**: Mitigation Applied - Increased pod count
- **2021-09-14 00:49:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 23:54:00 by rolling back production deployment DEP-0448 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
