# Incident Report: INC-0185 - Routing loop in Istio service mesh for insightcrm-ui

* **Severity:** P0
* **Linked Deployment:** DEP-0387
* **Linked PR:** PR-0199
* **Linked ADR:** None

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-08-11 23:30:00**: System Alert - Anomalous Metrics Detected
- **2021-08-11 23:32:00**: On-call Engineer Acknowledged Alert
- **2021-08-12 00:53:00**: Mitigation Applied - Rolled back deployment
- **2021-08-12 02:44:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 00:53:00 by rolling back production deployment DEP-0387 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
