# Incident Report: INC-0173 - Message lag spike on Kafka partition for platform-logging

* **Severity:** P1
* **Linked Deployment:** DEP-0361
* **Linked PR:** PR-0166
* **Linked ADR:** ADR-0042

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-07-28 16:02:00**: System Alert - Anomalous Metrics Detected
- **2021-07-28 16:14:00**: On-call Engineer Acknowledged Alert
- **2021-07-28 17:08:00**: Mitigation Applied - Increased pod count
- **2021-07-28 19:39:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 17:08:00 by rolling back production deployment DEP-0361 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
