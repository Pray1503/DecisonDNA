# Incident Report: INC-0080 - Message lag spike on Kafka partition for security-scanner

* **Severity:** P1
* **Linked Deployment:** DEP-0167
* **Linked PR:** PR-0089
* **Linked ADR:** ADR-0022

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-04-05 23:05:00**: System Alert - Anomalous Metrics Detected
- **2021-04-05 23:12:00**: On-call Engineer Acknowledged Alert
- **2021-04-06 00:19:00**: Mitigation Applied - Flushed cache
- **2021-04-06 03:49:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 00:19:00 by rolling back production deployment DEP-0167 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
