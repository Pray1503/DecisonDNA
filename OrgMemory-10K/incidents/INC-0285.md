# Incident Report: INC-0285 - Message lag spike on Kafka partition for visionai-training

* **Severity:** P1
* **Linked Deployment:** DEP-0590
* **Linked PR:** PR-0297
* **Linked ADR:** ADR-0072

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-11-23 05:39:00**: System Alert - Anomalous Metrics Detected
- **2021-11-23 05:43:00**: On-call Engineer Acknowledged Alert
- **2021-11-23 06:33:00**: Mitigation Applied - Increased pod count
- **2021-11-23 08:49:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 06:33:00 by rolling back production deployment DEP-0590 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
