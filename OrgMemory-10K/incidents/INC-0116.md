# Incident Report: INC-0116 - Out of memory (OOM) crash in insightcrm-analytics pod during batch processing

* **Severity:** P1
* **Linked Deployment:** DEP-0243
* **Linked PR:** PR-0130
* **Linked ADR:** ADR-0029

## Root Cause Summary
A memory leak in the Go/Python worker loop processing batch uploads. The worker accumulated pointers in a global slice and did not trigger garbage collection timely. Pod reached K8s limit (2Gi) and got OOMKilled.

## Incident Timeline
- **2021-05-11 10:26:00**: System Alert - Anomalous Metrics Detected
- **2021-05-11 10:28:00**: On-call Engineer Acknowledged Alert
- **2021-05-11 11:25:00**: Mitigation Applied - Flushed cache
- **2021-05-11 14:59:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 11:25:00 by rolling back production deployment DEP-0243 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Profile heap usage during batch tasks, reuse object buffers, and add strict memory limits to K8s configs with warnings at 80% usage.
