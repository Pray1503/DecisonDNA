# Incident Report: INC-0248 - Message lag spike on Kafka partition for visionai-inference

* **Severity:** P1
* **Linked Deployment:** DEP-0515
* **Linked PR:** PR-0267
* **Linked ADR:** None

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-10-19 09:06:00**: System Alert - Anomalous Metrics Detected
- **2021-10-19 09:21:00**: On-call Engineer Acknowledged Alert
- **2021-10-19 10:44:00**: Mitigation Applied - Increased pod count
- **2021-10-19 13:20:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 10:44:00 by rolling back production deployment DEP-0515 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
