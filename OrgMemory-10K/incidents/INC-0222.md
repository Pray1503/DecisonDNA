# Incident Report: INC-0222 - Unoptimized query on cloudsync-storage database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0462
* **Linked PR:** PR-0235
* **Linked ADR:** ADR-0059

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2021-09-21 23:04:00**: System Alert - Anomalous Metrics Detected
- **2021-09-21 23:18:00**: On-call Engineer Acknowledged Alert
- **2021-09-22 00:36:00**: Mitigation Applied - Flushed cache
- **2021-09-22 02:26:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 00:36:00 by rolling back production deployment DEP-0462 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
