# Incident Report: INC-0182 - Out of memory (OOM) crash in novacommerce-cart pod during batch processing

* **Severity:** P1
* **Linked Deployment:** DEP-0381
* **Linked PR:** PR-0174
* **Linked ADR:** ADR-0044

## Root Cause Summary
A memory leak in the Go/Python worker loop processing batch uploads. The worker accumulated pointers in a global slice and did not trigger garbage collection timely. Pod reached K8s limit (1Gi) and got OOMKilled.

## Incident Timeline
- **2021-08-05 18:34:00**: System Alert - Anomalous Metrics Detected
- **2021-08-05 18:42:00**: On-call Engineer Acknowledged Alert
- **2021-08-05 20:04:00**: Mitigation Applied - Flushed cache
- **2021-08-05 21:10:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 20:04:00 by rolling back production deployment DEP-0381 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Profile heap usage during batch tasks, reuse object buffers, and add strict memory limits to K8s configs with warnings at 80% usage.
