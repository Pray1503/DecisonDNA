# Incident Report: INC-0077 - Message lag spike on Kafka partition for security-scanner

* **Severity:** P1
* **Linked Deployment:** DEP-0159
* **Linked PR:** PR-0079
* **Linked ADR:** ADR-0019

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-04-03 14:38:00**: System Alert - Anomalous Metrics Detected
- **2021-04-03 14:43:00**: On-call Engineer Acknowledged Alert
- **2021-04-03 15:58:00**: Mitigation Applied - Flushed cache
- **2021-04-03 19:51:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 15:58:00 by rolling back production deployment DEP-0159 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
