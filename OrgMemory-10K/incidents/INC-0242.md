# Incident Report: INC-0242 - Message lag spike on Kafka partition for atlaspay-ledger

* **Severity:** P1
* **Linked Deployment:** DEP-0503
* **Linked PR:** PR-0251
* **Linked ADR:** ADR-0063

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-10-12 08:29:00**: System Alert - Anomalous Metrics Detected
- **2021-10-12 08:39:00**: On-call Engineer Acknowledged Alert
- **2021-10-12 09:48:00**: Mitigation Applied - Flushed cache
- **2021-10-12 13:32:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 09:48:00 by rolling back production deployment DEP-0503 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
