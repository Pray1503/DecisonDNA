# Incident Report: INC-0314 - Message lag spike on Kafka partition for atlaspay-portal

* **Severity:** P1
* **Linked Deployment:** DEP-0652
* **Linked PR:** PR-0333
* **Linked ADR:** None

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-12-21 04:26:00**: System Alert - Anomalous Metrics Detected
- **2021-12-21 04:39:00**: On-call Engineer Acknowledged Alert
- **2021-12-21 05:12:00**: Mitigation Applied - Flushed cache
- **2021-12-21 06:55:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 05:12:00 by rolling back production deployment DEP-0652 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
