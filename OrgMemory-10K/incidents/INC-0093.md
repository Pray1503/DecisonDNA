# Incident Report: INC-0093 - Message lag spike on Kafka partition for novacommerce-api

* **Severity:** P1
* **Linked Deployment:** DEP-0194
* **Linked PR:** PR-0099
* **Linked ADR:** ADR-0025

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-04-19 15:52:00**: System Alert - Anomalous Metrics Detected
- **2021-04-19 15:56:00**: On-call Engineer Acknowledged Alert
- **2021-04-19 17:09:00**: Mitigation Applied - Increased pod count
- **2021-04-19 19:00:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 17:09:00 by rolling back production deployment DEP-0194 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
