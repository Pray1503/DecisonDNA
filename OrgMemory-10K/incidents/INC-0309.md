# Incident Report: INC-0309 - Routing loop in Istio service mesh for atlaspay-gateway

* **Severity:** P0
* **Linked Deployment:** DEP-0639
* **Linked PR:** PR-0328
* **Linked ADR:** ADR-0079

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-12-18 17:49:00**: System Alert - Anomalous Metrics Detected
- **2021-12-18 18:01:00**: On-call Engineer Acknowledged Alert
- **2021-12-18 18:43:00**: Mitigation Applied - Rolled back deployment
- **2021-12-18 19:59:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 18:43:00 by rolling back production deployment DEP-0639 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
