# Incident Report: INC-0210 - Routing loop in Istio service mesh for cloudsync-desktop

* **Severity:** P0
* **Linked Deployment:** DEP-0438
* **Linked PR:** PR-0215
* **Linked ADR:** ADR-0054

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-09-06 08:25:00**: System Alert - Anomalous Metrics Detected
- **2021-09-06 08:36:00**: On-call Engineer Acknowledged Alert
- **2021-09-06 08:52:00**: Mitigation Applied - Rolled back deployment
- **2021-09-06 10:46:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 08:52:00 by rolling back production deployment DEP-0438 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
