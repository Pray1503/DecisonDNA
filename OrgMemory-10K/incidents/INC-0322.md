# Incident Report: INC-0322 - Message lag spike on Kafka partition for cloudsync-storage

* **Severity:** P1
* **Linked Deployment:** DEP-0670
* **Linked PR:** PR-0312
* **Linked ADR:** ADR-0075

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-12-31 22:26:00**: System Alert - Anomalous Metrics Detected
- **2021-12-31 22:40:00**: On-call Engineer Acknowledged Alert
- **2021-12-31 23:54:00**: Mitigation Applied - Increased pod count
- **2022-01-01 01:20:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 23:54:00 by rolling back production deployment DEP-0670 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
