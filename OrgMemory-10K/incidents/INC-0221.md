# Incident Report: INC-0221 - Routing loop in Istio service mesh for cloudsync-desktop

* **Severity:** P0
* **Linked Deployment:** DEP-0460
* **Linked PR:** PR-0212
* **Linked ADR:** ADR-0054

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-09-19 10:44:00**: System Alert - Anomalous Metrics Detected
- **2021-09-19 10:58:00**: On-call Engineer Acknowledged Alert
- **2021-09-19 12:07:00**: Mitigation Applied - Increased pod count
- **2021-09-19 15:32:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 12:07:00 by rolling back production deployment DEP-0460 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
