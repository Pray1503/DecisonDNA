# Incident Report: INC-0101 - Routing loop in Istio service mesh for platform-logging

* **Severity:** P0
* **Linked Deployment:** DEP-0211
* **Linked PR:** PR-0108
* **Linked ADR:** ADR-0023

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-04-28 18:07:00**: System Alert - Anomalous Metrics Detected
- **2021-04-28 18:14:00**: On-call Engineer Acknowledged Alert
- **2021-04-28 18:55:00**: Mitigation Applied - Increased pod count
- **2021-04-28 22:21:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 18:55:00 by rolling back production deployment DEP-0211 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
