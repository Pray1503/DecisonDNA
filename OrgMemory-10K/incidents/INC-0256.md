# Incident Report: INC-0256 - Message lag spike on Kafka partition for security-auth-proxy

* **Severity:** P1
* **Linked Deployment:** DEP-0532
* **Linked PR:** PR-0263
* **Linked ADR:** None

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-10-24 02:34:00**: System Alert - Anomalous Metrics Detected
- **2021-10-24 02:46:00**: On-call Engineer Acknowledged Alert
- **2021-10-24 03:08:00**: Mitigation Applied - Increased pod count
- **2021-10-24 04:33:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 03:08:00 by rolling back production deployment DEP-0532 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
