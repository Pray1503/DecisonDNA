# Incident Report: INC-0357 - Unoptimized query on atlaspay-ledger database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0744
* **Linked PR:** PR-0382
* **Linked ADR:** ADR-0093

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2022-01-26 10:24:00**: System Alert - Anomalous Metrics Detected
- **2022-01-26 10:36:00**: On-call Engineer Acknowledged Alert
- **2022-01-26 11:15:00**: Mitigation Applied - Rolled back deployment
- **2022-01-26 14:09:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 11:15:00 by rolling back production deployment DEP-0744 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
