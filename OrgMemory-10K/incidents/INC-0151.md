# Incident Report: INC-0151 - Unoptimized query on atlaspay-ledger database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0318
* **Linked PR:** PR-0146
* **Linked ADR:** ADR-0036

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2021-06-22 12:46:00**: System Alert - Anomalous Metrics Detected
- **2021-06-22 12:50:00**: On-call Engineer Acknowledged Alert
- **2021-06-22 13:36:00**: Mitigation Applied - Increased pod count
- **2021-06-22 14:10:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 13:36:00 by rolling back production deployment DEP-0318 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
