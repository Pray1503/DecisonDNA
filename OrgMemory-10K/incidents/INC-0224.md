# Incident Report: INC-0224 - Routing loop in Istio service mesh for novacommerce-api

* **Severity:** P0
* **Linked Deployment:** DEP-0464
* **Linked PR:** PR-0216
* **Linked ADR:** ADR-0055

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-09-23 01:08:00**: System Alert - Anomalous Metrics Detected
- **2021-09-23 01:10:00**: On-call Engineer Acknowledged Alert
- **2021-09-23 01:28:00**: Mitigation Applied - Flushed cache
- **2021-09-23 03:49:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 01:28:00 by rolling back production deployment DEP-0464 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
