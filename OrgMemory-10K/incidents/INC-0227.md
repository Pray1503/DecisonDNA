# Incident Report: INC-0227 - Message lag spike on Kafka partition for devops-ci-cd

* **Severity:** P1
* **Linked Deployment:** DEP-0472
* **Linked PR:** PR-0219
* **Linked ADR:** ADR-0057

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-09-26 22:30:00**: System Alert - Anomalous Metrics Detected
- **2021-09-26 22:42:00**: On-call Engineer Acknowledged Alert
- **2021-09-26 23:41:00**: Mitigation Applied - Rolled back deployment
- **2021-09-27 00:38:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 23:41:00 by rolling back production deployment DEP-0472 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
