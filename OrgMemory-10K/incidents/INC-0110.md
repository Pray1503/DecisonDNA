# Incident Report: INC-0110 - Unoptimized query on novacommerce-api database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0231
* **Linked PR:** PR-0116
* **Linked ADR:** ADR-0025

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2021-05-07 10:04:00**: System Alert - Anomalous Metrics Detected
- **2021-05-07 10:19:00**: On-call Engineer Acknowledged Alert
- **2021-05-07 11:13:00**: Mitigation Applied - Rolled back deployment
- **2021-05-07 14:53:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 11:13:00 by rolling back production deployment DEP-0231 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
