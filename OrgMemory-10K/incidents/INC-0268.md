# Incident Report: INC-0268 - Routing loop in Istio service mesh for security-scanner

* **Severity:** P0
* **Linked Deployment:** DEP-0560
* **Linked PR:** PR-0288
* **Linked ADR:** ADR-0070

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-11-08 08:48:00**: System Alert - Anomalous Metrics Detected
- **2021-11-08 08:56:00**: On-call Engineer Acknowledged Alert
- **2021-11-08 10:11:00**: Mitigation Applied - Increased pod count
- **2021-11-08 12:44:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 10:11:00 by rolling back production deployment DEP-0560 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
