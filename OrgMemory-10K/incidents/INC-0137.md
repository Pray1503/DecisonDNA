# Incident Report: INC-0137 - Routing loop in Istio service mesh for insightcrm-analytics

* **Severity:** P0
* **Linked Deployment:** DEP-0289
* **Linked PR:** PR-0127
* **Linked ADR:** ADR-0029

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-06-02 04:13:00**: System Alert - Anomalous Metrics Detected
- **2021-06-02 04:23:00**: On-call Engineer Acknowledged Alert
- **2021-06-02 05:10:00**: Mitigation Applied - Flushed cache
- **2021-06-02 06:05:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 05:10:00 by rolling back production deployment DEP-0289 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
