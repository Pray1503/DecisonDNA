# Incident Report: INC-0001 - Routing loop in Istio service mesh for atlaspay-ledger

* **Severity:** P0
* **Linked Deployment:** DEP-0003
* **Linked PR:** PR-0001
* **Linked ADR:** ADR-0001

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-01-12 15:59:00**: System Alert - Anomalous Metrics Detected
- **2021-01-12 16:08:00**: On-call Engineer Acknowledged Alert
- **2021-01-12 16:33:00**: Mitigation Applied - Increased pod count
- **2021-01-12 19:59:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 16:33:00 by rolling back production deployment DEP-0003 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
