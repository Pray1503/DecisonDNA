# Incident Report: INC-0009 - Message lag spike on Kafka partition for security-scanner

* **Severity:** P1
* **Linked Deployment:** DEP-0019
* **Linked PR:** PR-0012
* **Linked ADR:** ADR-0002

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-01-28 09:05:00**: System Alert - Anomalous Metrics Detected
- **2021-01-28 09:13:00**: On-call Engineer Acknowledged Alert
- **2021-01-28 09:36:00**: Mitigation Applied - Increased pod count
- **2021-01-28 12:26:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 09:36:00 by rolling back production deployment DEP-0019 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
