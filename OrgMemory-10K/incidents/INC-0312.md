# Incident Report: INC-0312 - Message lag spike on Kafka partition for insightcrm-analytics

* **Severity:** P1
* **Linked Deployment:** DEP-0648
* **Linked PR:** PR-0323
* **Linked ADR:** ADR-0080

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-12-19 13:02:00**: System Alert - Anomalous Metrics Detected
- **2021-12-19 13:11:00**: On-call Engineer Acknowledged Alert
- **2021-12-19 13:54:00**: Mitigation Applied - Flushed cache
- **2021-12-19 14:30:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 13:54:00 by rolling back production deployment DEP-0648 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
