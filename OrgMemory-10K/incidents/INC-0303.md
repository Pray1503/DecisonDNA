# Incident Report: INC-0303 - Cache stampede in novacommerce-cart for metadata queries

* **Severity:** P1
* **Linked Deployment:** DEP-0628
* **Linked PR:** PR-0317
* **Linked ADR:** ADR-0076

## Root Cause Summary
An eviction of high-frequency metadata cache keys in Redis occurred concurrently with a traffic spike. Thousands of pods hit the underlying database at once to re-fetch the metadata, locking tables.

## Incident Timeline
- **2021-12-11 13:52:00**: System Alert - Anomalous Metrics Detected
- **2021-12-11 14:02:00**: On-call Engineer Acknowledged Alert
- **2021-12-11 14:49:00**: Mitigation Applied - Rolled back deployment
- **2021-12-11 16:13:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 14:49:00 by rolling back production deployment DEP-0628 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement cache key locking/mutexes (single-flight pattern) so only one request updates the cache while others wait. Add jitter to cache TTLs.
