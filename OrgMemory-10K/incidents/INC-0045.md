# Incident Report: INC-0045 - Out of memory (OOM) crash in insightcrm-ui pod during batch processing

* **Severity:** P1
* **Linked Deployment:** DEP-0096
* **Linked PR:** PR-0055
* **Linked ADR:** None

## Root Cause Summary
A memory leak in the Go/Python worker loop processing batch uploads. The worker accumulated pointers in a global slice and did not trigger garbage collection timely. Pod reached K8s limit (1Gi) and got OOMKilled.

## Incident Timeline
- **2021-03-03 00:07:00**: System Alert - Anomalous Metrics Detected
- **2021-03-03 00:21:00**: On-call Engineer Acknowledged Alert
- **2021-03-03 01:01:00**: Mitigation Applied - Rolled back deployment
- **2021-03-03 04:41:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 01:01:00 by rolling back production deployment DEP-0096 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Profile heap usage during batch tasks, reuse object buffers, and add strict memory limits to K8s configs with warnings at 80% usage.
