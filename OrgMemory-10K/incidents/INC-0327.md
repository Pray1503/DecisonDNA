# Incident Report: INC-0327 - Routing loop in Istio service mesh for visionai-training

* **Severity:** P0
* **Linked Deployment:** DEP-0684
* **Linked PR:** PR-0346
* **Linked ADR:** ADR-0083

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2022-01-03 01:45:00**: System Alert - Anomalous Metrics Detected
- **2022-01-03 01:48:00**: On-call Engineer Acknowledged Alert
- **2022-01-03 02:21:00**: Mitigation Applied - Increased pod count
- **2022-01-03 04:38:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 02:21:00 by rolling back production deployment DEP-0684 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
