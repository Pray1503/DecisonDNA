# Incident Report: INC-0360 - Message lag spike on Kafka partition for visionai-training

* **Severity:** P1
* **Linked Deployment:** DEP-0750
* **Linked PR:** PR-0350
* **Linked ADR:** ADR-0085

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2022-01-31 09:54:00**: System Alert - Anomalous Metrics Detected
- **2022-01-31 09:57:00**: On-call Engineer Acknowledged Alert
- **2022-01-31 10:32:00**: Mitigation Applied - Flushed cache
- **2022-01-31 13:41:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 10:32:00 by rolling back production deployment DEP-0750 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
