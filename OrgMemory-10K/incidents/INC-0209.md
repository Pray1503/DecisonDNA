# Incident Report: INC-0209 - Routing loop in Istio service mesh for devops-ci-cd

* **Severity:** P0
* **Linked Deployment:** DEP-0434
* **Linked PR:** PR-0224
* **Linked ADR:** ADR-0057

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-09-04 22:48:00**: System Alert - Anomalous Metrics Detected
- **2021-09-04 22:53:00**: On-call Engineer Acknowledged Alert
- **2021-09-05 00:11:00**: Mitigation Applied - Flushed cache
- **2021-09-05 03:06:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 00:11:00 by rolling back production deployment DEP-0434 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
