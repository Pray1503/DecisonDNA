# Incident Report: INC-0263 - Message lag spike on Kafka partition for cloudsync-daemon

* **Severity:** P1
* **Linked Deployment:** DEP-0546
* **Linked PR:** PR-0256
* **Linked ADR:** ADR-0064

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-11-05 23:35:00**: System Alert - Anomalous Metrics Detected
- **2021-11-05 23:49:00**: On-call Engineer Acknowledged Alert
- **2021-11-06 01:08:00**: Mitigation Applied - Flushed cache
- **2021-11-06 02:18:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 01:08:00 by rolling back production deployment DEP-0546 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
