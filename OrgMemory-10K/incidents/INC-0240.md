# Incident Report: INC-0240 - Routing loop in Istio service mesh for security-auth-proxy

* **Severity:** P0
* **Linked Deployment:** DEP-0499
* **Linked PR:** PR-0254
* **Linked ADR:** None

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-10-10 10:18:00**: System Alert - Anomalous Metrics Detected
- **2021-10-10 10:25:00**: On-call Engineer Acknowledged Alert
- **2021-10-10 11:35:00**: Mitigation Applied - Flushed cache
- **2021-10-10 13:41:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 11:35:00 by rolling back production deployment DEP-0499 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
