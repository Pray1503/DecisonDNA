# Incident Report: INC-0225 - Routing loop in Istio service mesh for visionai-pipeline

* **Severity:** P0
* **Linked Deployment:** DEP-0468
* **Linked PR:** PR-0237
* **Linked ADR:** None

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-09-23 19:13:00**: System Alert - Anomalous Metrics Detected
- **2021-09-23 19:20:00**: On-call Engineer Acknowledged Alert
- **2021-09-23 20:40:00**: Mitigation Applied - Flushed cache
- **2021-09-23 23:04:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 20:40:00 by rolling back production deployment DEP-0468 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
