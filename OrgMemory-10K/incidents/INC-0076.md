# Incident Report: INC-0076 - Routing loop in Istio service mesh for security-scanner

* **Severity:** P0
* **Linked Deployment:** DEP-0161
* **Linked PR:** PR-0081
* **Linked ADR:** ADR-0019

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-04-03 10:25:00**: System Alert - Anomalous Metrics Detected
- **2021-04-03 10:28:00**: On-call Engineer Acknowledged Alert
- **2021-04-03 10:49:00**: Mitigation Applied - Increased pod count
- **2021-04-03 11:55:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 10:49:00 by rolling back production deployment DEP-0161 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
