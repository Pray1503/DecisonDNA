# Incident Report: INC-0033 - Message lag spike on Kafka partition for cloudsync-daemon

* **Severity:** P1
* **Linked Deployment:** DEP-0071
* **Linked PR:** PR-0046
* **Linked ADR:** ADR-0010

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-02-17 18:04:00**: System Alert - Anomalous Metrics Detected
- **2021-02-17 18:18:00**: On-call Engineer Acknowledged Alert
- **2021-02-17 19:23:00**: Mitigation Applied - Rolled back deployment
- **2021-02-17 23:12:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 19:23:00 by rolling back production deployment DEP-0071 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
