# Incident Report: INC-0066 - Message lag spike on Kafka partition for platform-monitoring

* **Severity:** P1
* **Linked Deployment:** DEP-0139
* **Linked PR:** PR-0074
* **Linked ADR:** ADR-0020

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-03-23 04:59:00**: System Alert - Anomalous Metrics Detected
- **2021-03-23 05:12:00**: On-call Engineer Acknowledged Alert
- **2021-03-23 06:27:00**: Mitigation Applied - Flushed cache
- **2021-03-23 10:27:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 06:27:00 by rolling back production deployment DEP-0139 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
