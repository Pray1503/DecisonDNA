# Incident Report: INC-0217 - Message lag spike on Kafka partition for cloudsync-storage

* **Severity:** P1
* **Linked Deployment:** DEP-0452
* **Linked PR:** PR-0236
* **Linked ADR:** ADR-0059

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-09-14 21:28:00**: System Alert - Anomalous Metrics Detected
- **2021-09-14 21:30:00**: On-call Engineer Acknowledged Alert
- **2021-09-14 22:46:00**: Mitigation Applied - Flushed cache
- **2021-09-15 00:21:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 22:46:00 by rolling back production deployment DEP-0452 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
