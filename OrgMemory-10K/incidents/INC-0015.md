# Incident Report: INC-0015 - Routing loop in Istio service mesh for platform-monitoring

* **Severity:** P0
* **Linked Deployment:** DEP-0031
* **Linked PR:** PR-0015
* **Linked ADR:** ADR-0003

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-02-05 11:07:00**: System Alert - Anomalous Metrics Detected
- **2021-02-05 11:12:00**: On-call Engineer Acknowledged Alert
- **2021-02-05 12:09:00**: Mitigation Applied - Flushed cache
- **2021-02-05 14:42:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 12:09:00 by rolling back production deployment DEP-0031 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
