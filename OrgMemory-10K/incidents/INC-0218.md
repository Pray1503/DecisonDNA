# Incident Report: INC-0218 - Unoptimized query on novacommerce-cart database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0454
* **Linked PR:** PR-0205
* **Linked ADR:** ADR-0053

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2021-09-15 10:25:00**: System Alert - Anomalous Metrics Detected
- **2021-09-15 10:35:00**: On-call Engineer Acknowledged Alert
- **2021-09-15 11:09:00**: Mitigation Applied - Flushed cache
- **2021-09-15 13:30:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 11:09:00 by rolling back production deployment DEP-0454 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
