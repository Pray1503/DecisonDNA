# Incident Report: INC-0283 - Routing loop in Istio service mesh for devops-ci-cd

* **Severity:** P0
* **Linked Deployment:** DEP-0586
* **Linked PR:** PR-0299
* **Linked ADR:** None

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-11-19 04:10:00**: System Alert - Anomalous Metrics Detected
- **2021-11-19 04:21:00**: On-call Engineer Acknowledged Alert
- **2021-11-19 05:49:00**: Mitigation Applied - Increased pod count
- **2021-11-19 06:32:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 05:49:00 by rolling back production deployment DEP-0586 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
