# Incident Report: INC-0241 - Message lag spike on Kafka partition for cloudsync-daemon

* **Severity:** P1
* **Linked Deployment:** DEP-0505
* **Linked PR:** PR-0262
* **Linked ADR:** ADR-0064

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-10-12 05:56:00**: System Alert - Anomalous Metrics Detected
- **2021-10-12 06:05:00**: On-call Engineer Acknowledged Alert
- **2021-10-12 07:34:00**: Mitigation Applied - Rolled back deployment
- **2021-10-12 08:04:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 07:34:00 by rolling back production deployment DEP-0505 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
