# Incident Report: INC-0125 - Routing loop in Istio service mesh for novacommerce-cart

* **Severity:** P0
* **Linked Deployment:** DEP-0267
* **Linked PR:** PR-0140
* **Linked ADR:** ADR-0033

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-05-21 04:08:00**: System Alert - Anomalous Metrics Detected
- **2021-05-21 04:10:00**: On-call Engineer Acknowledged Alert
- **2021-05-21 05:36:00**: Mitigation Applied - Flushed cache
- **2021-05-21 08:43:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 05:36:00 by rolling back production deployment DEP-0267 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
