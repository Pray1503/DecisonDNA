# Incident Report: INC-0154 - Message lag spike on Kafka partition for insightcrm-analytics

* **Severity:** P1
* **Linked Deployment:** DEP-0322
* **Linked PR:** PR-0157
* **Linked ADR:** ADR-0041

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-06-27 15:49:00**: System Alert - Anomalous Metrics Detected
- **2021-06-27 16:03:00**: On-call Engineer Acknowledged Alert
- **2021-06-27 17:11:00**: Mitigation Applied - Rolled back deployment
- **2021-06-27 19:10:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 17:11:00 by rolling back production deployment DEP-0322 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
