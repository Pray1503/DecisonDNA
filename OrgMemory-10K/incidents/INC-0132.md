# Incident Report: INC-0132 - Unoptimized query on atlaspay-portal database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0278
* **Linked PR:** PR-0144
* **Linked ADR:** ADR-0034

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2021-05-27 00:24:00**: System Alert - Anomalous Metrics Detected
- **2021-05-27 00:38:00**: On-call Engineer Acknowledged Alert
- **2021-05-27 01:10:00**: Mitigation Applied - Flushed cache
- **2021-05-27 04:56:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 01:10:00 by rolling back production deployment DEP-0278 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
