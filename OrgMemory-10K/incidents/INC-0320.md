# Incident Report: INC-0320 - Routing loop in Istio service mesh for insightcrm-analytics

* **Severity:** P0
* **Linked Deployment:** DEP-0665
* **Linked PR:** PR-0336
* **Linked ADR:** ADR-0080

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-12-28 16:12:00**: System Alert - Anomalous Metrics Detected
- **2021-12-28 16:22:00**: On-call Engineer Acknowledged Alert
- **2021-12-28 17:24:00**: Mitigation Applied - Increased pod count
- **2021-12-28 18:15:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 17:24:00 by rolling back production deployment DEP-0665 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
