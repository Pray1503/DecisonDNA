# Incident Report: INC-0012 - Message lag spike on Kafka partition for insightcrm-api

* **Severity:** P1
* **Linked Deployment:** DEP-0025
* **Linked PR:** PR-0016
* **Linked ADR:** ADR-0005

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-01-30 08:44:00**: System Alert - Anomalous Metrics Detected
- **2021-01-30 08:46:00**: On-call Engineer Acknowledged Alert
- **2021-01-30 09:42:00**: Mitigation Applied - Increased pod count
- **2021-01-30 11:54:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 09:42:00 by rolling back production deployment DEP-0025 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
