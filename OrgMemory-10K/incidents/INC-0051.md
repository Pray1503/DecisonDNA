# Incident Report: INC-0051 - Message lag spike on Kafka partition for atlaspay-gateway

* **Severity:** P1
* **Linked Deployment:** DEP-0110
* **Linked PR:** PR-0067
* **Linked ADR:** ADR-0016

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-03-08 16:24:00**: System Alert - Anomalous Metrics Detected
- **2021-03-08 16:39:00**: On-call Engineer Acknowledged Alert
- **2021-03-08 17:26:00**: Mitigation Applied - Increased pod count
- **2021-03-08 20:56:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 17:26:00 by rolling back production deployment DEP-0110 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
