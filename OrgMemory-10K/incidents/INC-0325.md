# Incident Report: INC-0325 - Out of memory (OOM) crash in insightcrm-analytics pod during batch processing

* **Severity:** P1
* **Linked Deployment:** DEP-0678
* **Linked PR:** PR-0339
* **Linked ADR:** ADR-0081

## Root Cause Summary
A memory leak in the Go/Python worker loop processing batch uploads. The worker accumulated pointers in a global slice and did not trigger garbage collection timely. Pod reached K8s limit (2Gi) and got OOMKilled.

## Incident Timeline
- **2022-01-02 07:49:00**: System Alert - Anomalous Metrics Detected
- **2022-01-02 07:58:00**: On-call Engineer Acknowledged Alert
- **2022-01-02 08:41:00**: Mitigation Applied - Flushed cache
- **2022-01-02 11:17:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 08:41:00 by rolling back production deployment DEP-0678 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Profile heap usage during batch tasks, reuse object buffers, and add strict memory limits to K8s configs with warnings at 80% usage.
