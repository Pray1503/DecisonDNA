# Incident Report: INC-0339 - Message lag spike on Kafka partition for cloudsync-desktop

* **Severity:** P1
* **Linked Deployment:** DEP-0708
* **Linked PR:** PR-0364
* **Linked ADR:** ADR-0090

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2022-01-14 03:28:00**: System Alert - Anomalous Metrics Detected
- **2022-01-14 03:33:00**: On-call Engineer Acknowledged Alert
- **2022-01-14 03:48:00**: Mitigation Applied - Increased pod count
- **2022-01-14 07:30:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 03:48:00 by rolling back production deployment DEP-0708 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
