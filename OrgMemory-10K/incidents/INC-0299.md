# Incident Report: INC-0299 - Unoptimized query on visionai-training database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0619
* **Linked PR:** PR-0295
* **Linked ADR:** ADR-0072

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2021-12-09 01:40:00**: System Alert - Anomalous Metrics Detected
- **2021-12-09 01:44:00**: On-call Engineer Acknowledged Alert
- **2021-12-09 03:07:00**: Mitigation Applied - Flushed cache
- **2021-12-09 04:38:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 03:07:00 by rolling back production deployment DEP-0619 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
