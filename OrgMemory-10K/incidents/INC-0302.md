# Incident Report: INC-0302 - Message lag spike on Kafka partition for atlaspay-gateway

* **Severity:** P1
* **Linked Deployment:** DEP-0626
* **Linked PR:** PR-0314
* **Linked ADR:** ADR-0079

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-12-11 12:38:00**: System Alert - Anomalous Metrics Detected
- **2021-12-11 12:52:00**: On-call Engineer Acknowledged Alert
- **2021-12-11 14:10:00**: Mitigation Applied - Rolled back deployment
- **2021-12-11 15:44:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 14:10:00 by rolling back production deployment DEP-0626 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
