# Incident Report: INC-0264 - Routing loop in Istio service mesh for platform-k8s-mesh

* **Severity:** P0
* **Linked Deployment:** DEP-0552
* **Linked PR:** PR-0273
* **Linked ADR:** None

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-11-07 05:22:00**: System Alert - Anomalous Metrics Detected
- **2021-11-07 05:35:00**: On-call Engineer Acknowledged Alert
- **2021-11-07 06:12:00**: Mitigation Applied - Rolled back deployment
- **2021-11-07 07:27:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 06:12:00 by rolling back production deployment DEP-0552 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
