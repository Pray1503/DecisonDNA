# Incident Report: INC-0284 - Unoptimized query on atlaspay-portal database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0588
* **Linked PR:** PR-0303
* **Linked ADR:** ADR-0073

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2021-11-22 04:05:00**: System Alert - Anomalous Metrics Detected
- **2021-11-22 04:08:00**: On-call Engineer Acknowledged Alert
- **2021-11-22 05:37:00**: Mitigation Applied - Flushed cache
- **2021-11-22 09:21:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 05:37:00 by rolling back production deployment DEP-0588 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
