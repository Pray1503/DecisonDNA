# Incident Report: INC-0265 - Routing loop in Istio service mesh for atlaspay-ledger

* **Severity:** P0
* **Linked Deployment:** DEP-0550
* **Linked PR:** PR-0272
* **Linked ADR:** None

## Root Cause Summary
A misconfigured VirtualService manifest in Terraform caused traffic to cycle between the canary deployment and the main service. Latency spiked and error rates reached 100% due to maximum hop recursion.

## Incident Timeline
- **2021-11-07 12:56:00**: System Alert - Anomalous Metrics Detected
- **2021-11-07 13:08:00**: On-call Engineer Acknowledged Alert
- **2021-11-07 13:32:00**: Mitigation Applied - Increased pod count
- **2021-11-07 14:57:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 13:32:00 by rolling back production deployment DEP-0550 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Add deployment linting checks for mesh configurations. Implement dry-run verification steps in CI/CD pipeline before applying mesh routes.
