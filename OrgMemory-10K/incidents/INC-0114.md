# Incident Report: INC-0114 - Unoptimized query on novacommerce-cart database after release

* **Severity:** P2
* **Linked Deployment:** DEP-0235
* **Linked PR:** PR-0124
* **Linked ADR:** ADR-0031

## Root Cause Summary
A new feature did a sequential scan on a table containing 10M+ rows because the foreign key index was omitted in the migration script. CPU spiked to 100% and query latency went from 5ms to 8000ms.

## Incident Timeline
- **2021-05-09 22:12:00**: System Alert - Anomalous Metrics Detected
- **2021-05-09 22:27:00**: On-call Engineer Acknowledged Alert
- **2021-05-09 23:45:00**: Mitigation Applied - Rolled back deployment
- **2021-05-10 02:37:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 23:45:00 by rolling back production deployment DEP-0235 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Require explain-plan checks in CI/CD pipelines for any new migration files. Enforce indexing guidelines for foreign keys.
