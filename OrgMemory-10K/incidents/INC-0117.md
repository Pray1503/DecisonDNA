# Incident Report: INC-0117 - Message lag spike on Kafka partition for novacommerce-cart

* **Severity:** P1
* **Linked Deployment:** DEP-0245
* **Linked PR:** PR-0121
* **Linked ADR:** ADR-0033

## Root Cause Summary
A slow consumer thread due to synchronous downstream HTTP calls. As partition size grew, processing fell behind by over 50,000 messages, delaying order processing in NovaCommerce.

## Incident Timeline
- **2021-05-12 05:56:00**: System Alert - Anomalous Metrics Detected
- **2021-05-12 06:01:00**: On-call Engineer Acknowledged Alert
- **2021-05-12 06:30:00**: Mitigation Applied - Rolled back deployment
- **2021-05-12 09:19:00**: Incident Resolved - System metrics stabilized

## Resolution Details
Applied mitigation at 06:30:00 by rolling back production deployment DEP-0245 or applying hotfix. Monitored CPU and error rates until they returned to baseline levels.

## Lessons Learned
Implement worker pool concurrency in consumer code, wrap calls in circuit breakers, and monitor consumer lag metrics to trigger auto-scaling.
