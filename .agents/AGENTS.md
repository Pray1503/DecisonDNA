# Workspace Rules

## Detailed Error Reporting
When reporting or debugging errors, the AI assistant must provide precise details. This includes:
- The exact file and path where the error occurred.
- The specific line number (e.g., "line 498").
- The exact phase or operation during which the error occurred (e.g., "during commit 56", "during ingestion step 3").
- The full, relevant stack trace or error message.
